# Code of Conduct

## Purpose

Bible is an open public project intended to be useful, practical, and welcoming to contributors from different backgrounds, disciplines, and experience levels.

This Code of Conduct exists to support constructive participation and to maintain a professional, respectful environment for discussion and collaboration.

## Expected behaviour

Participants in this project are expected to:

- communicate respectfully
- critique ideas, proposals, and implementations rather than people
- assume good faith where reasonable
- keep discussions relevant and constructive
- contribute in a way that improves the quality of the project
- respect the maintainer's role in shaping project direction and editorial standards

## Unacceptable behaviour

The following behaviour is not acceptable in project spaces, including issues, pull requests, discussions, and related communications:

- harassment, abuse, or intimidation
- personal attacks or insulting language
- discriminatory or hateful conduct
- trolling, provocation, or bad-faith argument
- repetitive hostile behaviour after a decision has been made
- doxxing or sharing private information without permission
- spam, self-promotional abuse, or irrelevant solicitation
- deliberately disruptive behaviour that damages the project's working environment

## Scope

This Code of Conduct applies to public interactions in the project repository and associated project communications relating to Bible.

## Maintainer responsibility

The maintainer is responsible for interpreting and enforcing this Code of Conduct.

The maintainer may take any action considered appropriate to protect the project and its contributors, including:

- asking for behaviour to stop
- moderating or closing discussions
- declining or locking pull requests
- removing comments
- restricting participation

## Reporting

If you experience or observe behaviour that violates this Code of Conduct, report it via:

- Email: `support@osipov.uk`
- Website: `https://www.osipov.uk`
- LinkedIn: `https://www.linkedin.com/in/igorosipov/`

## Enforcement

Responses to reported or observed behaviour may vary depending on severity, context, and pattern.

Possible responses include:

- informal warning
- request to change behaviour
- comment or thread moderation
- temporary restriction
- permanent exclusion from participation in project spaces

## Project standard

Bible aims to maintain a tone that is:

- respectful
- direct
- practical
- serious
- collaborative

Disagreement is acceptable.
Personal hostility is not.
