# Contributing to Bible

Thank you for your interest in improving Bible.

Bible is an open development handbook for teams, developers, founders, and agencies building with AI coding agents. The project is publicly maintained on GitHub and is intended to improve over time through practical contributions from the community.

## Principles for contributions

Please contribute changes that make the handbook:

- clearer
- more correct
- more practical
- more current
- more reusable across projects and teams
- better structured for both humans and AI agents

Good contributions usually improve one or more of the following:

- governance models
- engineering workflows
- agent operating rules
- multi-agent coordination
- safety and environment controls
- design-system and token discipline
- review and QA practices
- repo structure and maintainability
- prompts, templates, and implementation examples

## Before you open a pull request

Please try to keep changes:

- specific
- well-scoped
- easy to review
- internally consistent with the rest of the project

Where relevant, explain:

- what problem the change solves
- why the current text is insufficient
- whether the change is tool-specific or tool-agnostic
- whether the change is intended for all users or only a subset

If your change is substantial, it is helpful to open an issue first.

## Preferred style

Contributions should aim for:

- direct, clear writing
- practical guidance over theory
- minimal fluff
- explicit tradeoffs where useful
- modern, realistic workflows
- wording that is useful to both human teams and AI-assisted development workflows

Avoid:

- vague motivational language
- unnecessary marketing tone
- stack-specific assumptions unless clearly labelled
- overfitting guidance to a single vendor or IDE unless intentionally documented as such

## File and structure changes

You may propose:

- new handbook sections
- edits to existing sections
- examples
- templates
- governance files
- workflow definitions
- supporting website/discovery files such as SEO, crawler, and metadata assets

Please keep naming and structure consistent with the project.

## Licensing of contributions

By submitting a contribution to this repository, you agree that your contribution will be licensed under the repository's MIT License.

## Upstream-first request

You are free to use, adapt, fork, and commercialise this project under the repository license.

If you improve Bible, please contribute those improvements back upstream by pull request where practical, so the main public version can continue to improve for everyone.

This is a strong project preference, even where it is not a legal requirement.

## Attribution and official project reference

If you build on Bible, please reference the original project where appropriate:

- GitHub: `https://github.com/nicolapitersky/Bible`
- Website: `https://www.osipov.uk/Bible`

Please do not imply that your fork, derivative, service, or implementation is the official Bible project unless you have explicit permission to do so.

## Review and merge

All pull requests are reviewed at the discretion of the maintainer.

Submitting a pull request does not guarantee merge.

Changes may be edited, reorganised, or declined in order to preserve the quality, direction, and coherence of the project.
