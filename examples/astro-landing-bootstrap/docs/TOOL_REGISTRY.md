## Adding a Tool

Before adding any new tool:
1. Check this list — does something here already do it?
2. Check the handbook TOOLING.md — is there an org-wide approved alternative?
3. Evaluate: maintained? secure? necessary?
4. Add here with version and docs link
5. Create an ADR if it's architecturally significant
