# Support

## Project status

Bible is an open public project maintained by Igor Osipov.

Canonical repository:

`https://github.com/nicolapitersky/Bible`

Public website mirror:

`https://www.osipov.uk/Bible`

## What support covers

Support may include:

- questions about the project
- clarification requests
- contribution guidance
- repository or website issues
- governance-related questions
- reporting broken links, stale content, or obvious errors

## Preferred channels

For support or project contact:

- Email: `support@osipov.uk`
- Website: `https://www.osipov.uk`
- LinkedIn: `https://www.linkedin.com/in/igorosipov/`

## Before contacting directly

Where appropriate, please use the repository first:

- open an issue for public, non-sensitive questions
- open a pull request for concrete fixes or improvements
- use direct contact for sensitive, private, or non-public matters

## Response expectations

Bible is maintained as a public project and responses are provided at maintainer discretion.

Support availability, response speed, implementation work, or acceptance of suggestions is not guaranteed.

## Commercial use and implementation

Bible is available for free use and reuse under the repository license.

If you build on Bible in your own work, products, consulting, or internal engineering processes, you are encouraged to reference the original project where appropriate:

- `https://github.com/nicolapitersky/Bible`
- `https://www.osipov.uk/Bible`

Please do not imply endorsement, partnership, or official status without explicit permission.

## Contributing back

If you improve Bible or derive useful improvements from it, please contribute those improvements upstream by pull request where practical so the public project can continue to improve for everyone.
