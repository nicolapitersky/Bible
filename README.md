# Complete Development Handbook — The Bible

> The single source of truth for all agentic development at this organisation.
> Every agent, every project, every IDE reads this before writing a single line of code.

**Repo:** `https://github.com/nicolapitersky/Bible`  
**Current version:** `v2.0.0`

---

## What This Is

This is not a style guide. It is a **binding contract** between the human director and every AI development agent. It exists because AI agents are powerful but amnesiac — they forget context between sessions, reinvent tools that already exist, write to the wrong cloud project, and produce inconsistent UI. This handbook prevents all of that by establishing laws, not suggestions.

## One-Command Bootstrap

```bash
curl -sSL https://raw.githubusercontent.com/nicolapitersky/Bible/main/scripts/bootstrap.sh | bash
```

This clones the handbook, detects your stack and IDE, copies scripts into your project, and prints the exact prompt to paste into Claude Code, Cursor, or Windsurf.

## How Agents Access This

```bash
git clone https://github.com/nicolapitersky/Bible.git /tmp/handbook
# Then: "Read /tmp/handbook/BOOTSTRAP.md and follow it completely."
```
